## Engineering records
The remaining files are working records kept as written: test plans and
evidence for specific surfaces (search, sidebar transfers, layout and transient
dialogs, file safety, disk images, and others), audits, and investigations of
individual bugs. They describe how a feature was verified or why it changed,
including the testing tools and coordination used at the time. They are not
user documentation and may describe states that have since changed.

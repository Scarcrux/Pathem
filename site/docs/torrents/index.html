Manage torrent transfers

Add a deliberate transfer, inspect its destination, control activity, and understand that completed downloads can seed.

On this page

  • Check the destination and network implications
  • Add and inspect a transfer
  • Stop, remove, or retain downloaded data

Check the destination and network implications

Use a torrent or magnet from a source you trust and content you intend to share. BitTorrent activity communicates with other peers; a completed download can continue uploading as a seed. It is not a private cloud download.

Confirm the download directory and available space before adding a large transfer. The torrent download-path preference falls back to Downloads if its configured location is empty or no longer exists. Check the actual displayed destination rather than relying on an old setting.

Add and inspect a transfer

  1. Open Torrents from Command Palette or the Tools menu.
  2. Use the torrent interface to add a .torrent file or paste a magnet link. For a selected local .torrent file, Add to Torrents is also available.
  3. If another application hands Pathem a torrent or magnet, review the incoming confirmation. Confirmation is enabled by default to prevent an unintended background add.
  4. Review the transfer name, available file selection, and destination. A magnet may need to retrieve metadata before it can show the full file list.
  5. Watch progress and status, not just the presence of a row. Check peers and trackers if a transfer remains idle; no available peers is different from a filesystem write failure.
  6. Use Pause when you want activity to stop temporarily. Resume only when the network and destination are appropriate.

Stop, remove, or retain downloaded data

  1. Inspect whether a finished transfer is still seeding. Pause it if you do not want further peer activity.
  2. Use Remove only after reading whether the action keeps or deletes downloaded files. Removing a transfer and deleting its data are different choices.
  3. Set upload/download or related limits in the torrent controls as needed, then verify the displayed behavior. Limits and experimental transport options are not guarantees of anonymity or connectivity.
  4. After restarting Pathem, inspect restored transfers before assuming they are paused or complete. Persistent state lets transfers resume; it is not proof that a prior download finished successfully.
Keep in mind

Public-network, router, and other-client interoperability depends on the real environment. A local test does not guarantee inbound peer reachability on every network.

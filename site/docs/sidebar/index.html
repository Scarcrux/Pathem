Favorites, sidebar groups, and recent folders

Keep frequently used locations close, organize shortcuts, and avoid confusing a shortcut with the folder it points to.

On this page

  • Make a useful set of favorites
  • Use sidebar destinations safely
  • Understand Recents and compact mode

Make a useful set of favorites

  1. Open a frequently used folder in a pane and confirm its full path. Identically named cloud and local folders may be different locations.
  2. Right-click the sidebar and choose Add Current Folder when available. Confirm the resulting shortcut opens the intended directory.
  3. Reorder favorite shortcuts by dragging their sidebar rows. Use the sidebar's group controls to separate work, personal projects, or temporary tasks.
  4. Use the shortcut's context menu to rename its display label or change its icon when available. A shortcut label is not the same as renaming the folder on disk.
  5. Remove an unused shortcut using its sidebar context menu. Read the action carefully: removing a place from the sidebar should not be confused with trashing files in a pane.

Use sidebar destinations safely

  1. Click a sidebar folder to browse it in the active pane. Check which pane is active before changing locations.
  2. To copy or move files there, opening the destination in a pane first gives you a clear path to inspect. Then use Paste or an explicit Copy To… or Move To… action.
  3. If dropping onto a sidebar destination, inspect the drag operation and target row before releasing. Reordering a shortcut and transferring a file use different drop zones.
  4. For cloud locations and volumes, check availability before starting a transfer. A sidebar row can remain useful even when its underlying provider is disconnected.

Understand Recents and compact mode

Recents can be based on recently modified or recently opened files. Pathem defaults to recently modified; this can differ from what you expect from Finder's Recents. Change the Recents basis in Settings if you want the other behavior.

Compact sidebar mode uses icons with less space. Turn it off when learning unfamiliar places, particularly when several services contain a Documents or Downloads folder. Monochrome icons are another independent appearance choice.

A recent location or favorite is a reference to a path. It neither backs up the contents nor guarantees that an external volume is mounted.

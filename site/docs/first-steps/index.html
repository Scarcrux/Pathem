Your first five minutes

Learn the two-pane window, create a practice folder, and complete a small file operation without risking important data.

On this page

  • Prepare a harmless practice folder
  • Take a first tour
  • Find actions without memorizing menus
  • What to learn next

Prepare a harmless practice folder

Start with disposable sample files, not your only copy of an important document. Each pane has its own folder and tabs. Clicking inside a pane makes it the source for most commands; the other pane is often the destination.

Menu labels in these guides use the English interface. Keyboard shortcuts are the defaults, so customized bindings can differ. On keyboards that use F-keys for media controls, you may need Fn or Globe with an F-key.

Take a first tour

  1. Open a trusted Pathem build and click the left pane. Use the path bar or the sidebar to open a folder you control.
  2. Create a folder with Command-Shift-N and name it Pathem Practice. Double-click it to enter it; use Command-Up to go to its parent.
  3. Place a disposable text file in the practice folder. Select it and press Space to try Quick Look, then dismiss the preview.
  4. Select the same file and press Return to rename it. Return starts renaming; use double-click or Command-Down to open a selected item.
  5. Click the other pane and open a different practice folder. Click back in the source pane and run Copy to Other Pane from the command palette, or use F5.
  6. Check that the copied file appears in the destination and the original remains in the source. Use this visible source/destination check before larger transfers.
Keep in mind

Do not use a move as your first test. A copy makes it easier to understand which pane owns the selection while keeping the original in place.

Find actions without memorizing menus

  1. Press Command-K to open Command Palette. Command-Shift-P is also a default palette binding.
  2. Type an action such as New Folder, View Options, Connections, or Preferences. Select the intended command rather than an action with a similar name.
  3. If a command is unavailable, close the palette and check its prerequisites: an active pane, a selection, a local folder, or an appropriate file type.
  4. Open Preferences when you are ready to adjust dates, drag behavior, or appearance. Change one setting at a time, then return to your practice folder to see its effect.

What to learn next

Use the copy/move guide before working with important folders. The views guide explains which choices are saved for a folder and which are global defaults. The troubleshooting guide starts with reversible checks rather than resetting app data.

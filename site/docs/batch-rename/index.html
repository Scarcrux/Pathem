Rename many files with a preview

Build a repeatable renaming rule, inspect every proposed name, and catch collisions before applying it.

On this page

  • Prepare the selection
  • Create and inspect a naming rule
  • Reuse a reviewed rule

Prepare the selection

Start with files in one local working folder and keep a backup of important originals. A preview is a planning aid, not a replacement for a backup. Narrow the selection before opening Batch Rename so unrelated files are not part of the plan.

For a first test, use sample names such as scan-a.txt and scan-b.txt. Keep the extension outside the transformation unless changing it is intentional.

Create and inspect a naming rule

  1. Select the target files and run Batch Rename… from Command Palette.
  2. Use Find and Replace for a shared piece of text. Leave Regex off unless you specifically need a regular expression and understand what it matches.
  3. Use Prefix or Suffix to add consistent text, or choose a case conversion. Make one change at a time and inspect the Current and New name columns.
  4. For a numbered sequence, enable Numbering and set Start and Pad. Check the actual preview order rather than assuming it matches the order you clicked files.
  5. Leave Include extension off for ordinary base-name edits. If enabled, confirm that each resulting extension still describes its file.
  6. Read the entire preview and resolve any collision or invalid-name warning. Do not accept a transformation merely because the first row looks right.
  7. Choose Rename only when the plan is correct. Wait for completion and inspect the folder; if an operation fails, review which names actually changed before retrying.

Reuse a reviewed rule

  1. After checking the preview, use the preset Save control to name a reusable rule.
  2. On a later batch, select that preset and inspect the new preview against the new files. A saved rule does not guarantee collision-free results in a different folder.
  3. Cancel the panel when experimenting if you do not want to apply the plan. Deleting a preset removes the saved rule, not the selected files.
Keep in mind

Metadata tokens can depend on real file metadata. If a token yields an unexpected name or missing value, stop and inspect that file instead of applying the entire batch blindly.

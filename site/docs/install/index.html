Installation and permissions

Download the notarized release, install it, keep it up to date, and grant Full Disk Access when you need it.

On this page

  • Before you start
  • Install Pathem
  • Grant Full Disk Access only when needed
  • Keep Pathem up to date
  • Build from source

Before you start

Pathem requires macOS 15 or later and runs natively on Apple Silicon and Intel Macs. The release is a free download from GitHub: a disk image that is Developer ID signed and notarized by Apple, so macOS opens it without warnings.

Download it only from pathem.app or the project's GitHub Releases page. Do not download an app with the same name from elsewhere, and never disable macOS security protections to make a copy run.

Install Pathem

  1. Download the latest release from https://github.com/Scarcrux/Pathem/releases/latest (the Download button on pathem.app goes there). Choose the .dmg file.
  2. Open the disk image and drag Pathem to the Applications folder shown next to it. Do not run Pathem from inside the mounted disk image.
  3. Eject the disk image, then open Pathem from Applications. macOS may ask once whether to open an app downloaded from the internet; it names the publisher, Scarcrux LLC.
  4. If you are replacing an earlier copy, finish or pause any file operations in it and quit it first.
  5. Open a normal folder in your home directory first, and confirm you can browse and preview a harmless test file before granting broader access.
Keep in mind

If macOS says the app is damaged or cannot be verified, delete that copy and download it again from the Releases page instead of removing quarantine or disabling Gatekeeper.

Grant Full Disk Access only when needed

  1. If a protected folder reports an access error, open System Settings, then Privacy & Security, then Full Disk Access.
  2. Add the installed Pathem.app and enable its entry if you want it to browse protected locations. This is a broad permission; grant it only to a build you trust.
  3. Quit and reopen Pathem if macOS requests it. Return to the same folder and retry.
  4. If access still fails, check that the entry points to the installed app, not a discarded source-build copy. Volume permissions, disconnected servers, and online-only cloud files are separate issues.
Keep in mind

Do not grant Accessibility or Screen Recording merely to browse files. These are separate macOS permissions, not substitutes for filesystem access.

Keep Pathem up to date

  1. Pathem checks for updates automatically. When a new version has downloaded, an Update Ready button appears in the window's title bar; click it to see what changed and install it.
  2. To check now, choose Check for Updates from the Pathem menu, or use Check for Updates Now in Settings, Updates.
  3. To stop automatic checks, turn off Check for updates automatically in Settings, Updates. You can still check by hand.
  4. Pathem asks before it installs an update. To install updates without being asked, turn on Automatically download and install updates in Settings, Updates (Pathem 0.9.2 or later). It works only while automatic checks are on.
  5. If Pathem says updates are not set up for this build, it is a source or unsigned build. Download the latest release from GitHub; release builds update themselves.
Keep in mind

Updates come only from the project's GitHub releases and are verified with a signing key built into Pathem before they install.

Build from source

Developers can build Pathem from the public repository with the selected Xcode toolchain: make run builds and launches a development copy, and make app assembles a local application bundle. A source build does not need a paid Apple Developer account.

make install can stop a running Pathem and its helper processes while replacing the app, so finish transfers and save work first. A source build is not notarized and does not update itself.

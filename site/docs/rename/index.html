Rename a file and use name suggestions

Rename without moving a file, preserve its extension, and apply on-device suggestions only when you choose.

On this page

  • Rename one selected item
  • Try an on-device filename suggestion
  • If renaming does not complete

Rename one selected item

  1. Select exactly one item in the intended folder. Press Return or F2, or run the Rename action.
  2. Edit the name in the inline field or Rename dialog. Use a descriptive base name and keep the extension unless you intend to change the file type association.
  3. Confirm the name. If Pathem warns about an extension change, review the old and new extensions before proceeding.
  4. Verify the item under its new name in the same folder. Renaming may change its sorted position; it does not mean the file moved into a different directory.

Try an on-device filename suggestion

  1. Open Settings > Layout and enable Suggest filenames when renaming (on-device AI) if it is not already enabled.
  2. Use a local, downloaded file on a Mac with the required Apple Intelligence model available. A cloud placeholder must be downloaded before its contents can be used.
  3. Start Rename or the available AI Rename action. Continue typing your own name if you prefer; a response should not replace what you typed by itself.
  4. Read the proposed name. Choose Use Suggested Name only if you want to put it into the editable field.
  5. Review the final field, including its extension, then choose Rename. Cancel closes the dialog without accepting the suggested name.
Keep in mind

Apple's on-device language-model features require macOS 26 and an available Apple Intelligence model. A disabled setting, unsupported Mac, unavailable model, or remote item is not evidence that ordinary renaming is broken.

If renaming does not complete

Check for a read-only folder, an existing destination name, or a provider restriction. Avoid names containing a path separator; a rename field is not a destination-path field.

Do not navigate between unrelated local and remote locations while accepting a remote rename. If the operation context changed, cancel and start again in the correct folder.

If a long name is only partly visible, move the caret through the field to inspect it rather than shortening a meaningful name just to fit the dialog. Use Batch Rename for a deliberate multi-file naming rule.

Tags, smart locations, and flat views

Organize references to files without mistaking a collected or flattened view for a new physical folder.

On this page

  • Apply and inspect tags
  • Work safely in collected results
  • Separate browsing from reorganization

Apply and inspect tags

  1. Select a small set of local files that support tagging. Use the available Tags actions in the context menu or command palette.
  2. Assign a tag and confirm its label or color appears on the selected files. Filesystem or provider limitations may make tagging unavailable.
  3. Use a tag location in the sidebar or sort/group by Tags to inspect the tagged items.
  4. Use Clear Tags only when you intend to remove their tag metadata. Clearing a tag is different from removing a shortcut or moving a file.

Work safely in collected results

  1. Open the smart location or collection you need, or use Add to Collection… for a supported selection.
  2. Inspect each item's location. Two identically named results can belong to different real directories.
  3. Reveal an item in its actual folder before a destructive operation if its origin is unclear.
  4. When using Flat View, remember that items may come from multiple subfolders. A flat listing changes what is shown; it is not a request to physically move all items into one directory.

Separate browsing from reorganization

A tag, smart result, collection, or flat view can provide another way to find an item while leaving its actual path unchanged. Moving, renaming, trashing, or applying an organization plan changes the real file instead.

Organize Folder… is an explicit file-management workflow, not merely a visual grouping setting. Preview its proposed destinations and keep a backup before applying a large plan. For a purely visual arrangement, use Group By in the folder view.

If a smart view is unexpectedly empty, check the underlying query, scope, permissions, and provider availability. Do not create duplicate copies of files just because one derived view fails to show them.

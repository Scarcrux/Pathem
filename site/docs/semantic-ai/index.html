Semantic search and on-device AI

Understand which tools use semantic embeddings, which require Apple Intelligence, and how to review suggestions safely.

On this page

  • Separate semantic search from the language model
  • Search a local folder by topic
  • Opt into image OCR when useful
  • Review AI output before acting

Separate semantic search from the language model

Semantic search uses Apple's NaturalLanguage embeddings to rank local filenames and supported text by meaning. It is not the same as an Apple Intelligence language-model request and does not require Apple Intelligence just to use the semantic-search workflow.

Ask Pathem and AI filename suggestions have different requirements. The Apple on-device language model requires macOS 26, supported hardware, and an available Apple Intelligence model. Model availability can depend on the Mac's current configuration; the app reports availability rather than making an unsupported Mac download a third-party model.

Search a local folder by topic

  1. Open a small local folder containing downloaded documents you recognize. Start with a controlled sample so you can judge whether the results make sense.
  2. Run Semantic Search This Folder… from Command Palette.
  3. Describe the topic, such as notes about planning a garden, rather than typing an exact filename. Allow indexing work to finish before judging the ranking.
  4. Open or reveal a result and inspect the actual document. A high semantic rank indicates similarity, not proof that the contents answer your question.
  5. If you know a precise filename or phrase, compare with ordinary Search This Folder…. An exact search may be more useful than a semantic ranking.

Opt into image OCR when useful

  1. Keep OCR off for your first semantic-search test. It is disabled by default and can add indexing cost.
  2. If your task requires text inside images, enable the search OCR preference or use Toggle Image OCR in Search.
  3. Repeat the test with a downloaded image containing clear text. Check the result itself for recognition mistakes.
  4. Turn OCR off again if you do not need it or indexing becomes expensive. Do not expect OCR to recover text from every image or every cloud placeholder.

Review AI output before acting

Use Ask Pathem (Natural Language)… only for a task you can inspect. Review the interpreted command and any confirmation before accepting a file-changing operation. For an important move, the explicit Copy To… or Move To… command is easier to verify.

Filename suggestions should not overwrite your typed name until you choose Use Suggested Name. An unavailable or failed model does not prevent manual renaming. Cloud placeholders must be downloaded deliberately if their content is needed.

On-device processing describes these AI features; it does not mean all of Pathem is offline. Remote transfers, cloud providers, torrents, and update checks can use the network for their own purposes.

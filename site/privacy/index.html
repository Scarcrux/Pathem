Privacy

Pathem does not collect data about you or your files. There is no analytics, telemetry, crash reporting, or advertising in the app, and Pathem does not upload your files or file names anywhere.

Last updated 2026-11-24

What stays on your Mac

  • Your files. Browsing, searching, previews, and file operations all happen locally. Pathem reads folders so it can list them and does not send what it reads to anyone.
  • On-device AI. The AI command bar uses Apple's on-device FoundationModels framework, and semantic search uses Apple's NaturalLanguage embeddings. Both run on your Mac. Pathem has no cloud AI service and sends no prompts or file contents to one.
  • Full Disk Access. This is optional and you grant it yourself in System Settings. Pathem uses it only so it can browse protected folders. Nothing it can see through it is uploaded.

Network connections Pathem makes

  • Update checks. Pathem uses Sparkle to look for new versions. Automatic checks are on by default and can be turned off in Settings, Updates. Each check requests the update feed (an appcast file) published with the project's GitHub releases, so that server sees an ordinary web request from your IP address. Pathem does not enable Sparkle's system profiling, so no hardware or software inventory is attached.
  • Themes. Opening the Themes gallery in Settings, Appearance may request the public catalog from Amazon CloudFront. Pathem does not contact the catalog at any other time. CloudFront receives an ordinary web request from your IP address. This request does not include your local files, file names, installed themes, or search text. Preparing a theme submission creates a local file. If you attach that file to a public GitHub issue, the theme, attribution, and screenshots you chose become public.
  • Torrents. Pathem talks to the BitTorrent network only when you use the built-in torrent client. When you add a magnet link or a .torrent file, it contacts the trackers listed there, DHT peers, and any web seeds the magnet names. Peers in a swarm can see your IP address, as with any torrent client. Torrents you added earlier keep going across restarts.
  • Remote connections. SFTP, FTP, FTPS, WebDAV, Amazon S3, Azure Blob, and similar connections go only to servers you configure, using the details you enter. Pathem has no server of its own in that path.

Passwords and credentials

When you connect to a remote server, Pathem asks for the password or key passphrase. If you tick Remember in Keychain, it is stored in your macOS login Keychain. If you leave that unticked, it is used for that connection and not saved. Pathem does not send credentials anywhere except to the server you are connecting to.

This website

pathem.app is a static site hosted on Cloudflare Pages. It sets no cookies, shows no ads, and loads no third-party fonts or images. The home page has one small script of its own for the view carousel and scroll effects.

The site uses Cloudflare Web Analytics to count visits. Cloudflare loads a small script from static.cloudflareinsights.com that reports which page was viewed, the referring site, your browser and device type, your country, and how quickly the page loaded. Cloudflare states that it does not use cookies or local storage and does not fingerprint visitors. We see only aggregate counts, never individual visitors. Cloudflare also adds a small script that hides the contact address below from spam bots. Like any host, Cloudflare keeps standard server logs of requests.

The analytics apply to this website only. The Pathem app itself contains no analytics.

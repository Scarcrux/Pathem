# pathem

Name reserved for [Pathem](https://pathem.app), a fast, native macOS file
manager (dual pane, keyboard driven, Swift and AppKit, no Electron).

This npm package is a placeholder, not the app. Pathem ships as a notarized
macOS download: see [pathem.app](https://pathem.app) or
[github.com/Scarcrux/Pathem](https://github.com/Scarcrux/Pathem).
